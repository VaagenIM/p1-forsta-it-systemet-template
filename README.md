# P1 – Forstå IT-systemet

## Oppdrag

Undersøk og dokumenter **hele IT-laben** slik at en annen elev kan forstå hva systemet består av, hvordan delene er koblet sammen og hvilke avhengigheter systemet har.

Begynn ved egen stasjon og følg forbindelsene videre til den delte nettverksinfrastrukturen, tjenestene, serverne og de virtuelle ressursene.

**Classroom50-invitasjon:** Lenken publiseres i Teams-kanalen. Elevrepoet skal være privat.

## Start her

1. Åpne Classroom50-invitasjonen og opprett ditt private elevrepo.
2. Gjennomfør [startsjekken](ressurser/programvare.md#startsjekk), og bruk støtteveien hvis noe mangler.
3. Åpne planen for aktuell uke, og gjør bare arbeidssteget som står for dagen.

Hvert dagssteg peker til arbeidsfilen, hovedverktøyet og kontrollpunktet du trenger. Registrer en liten, sammenhengende endring med Git når kontrollpunktet er nådd.

## Regler

- Skriv for en leser som ikke kjenner systemet fra før.
- Bruk samme navn eller ID i komponentoversikten, diagrammene og systemoversikten.
- Ikke kopier samme informasjon flere steder; lenk til detaljene.
- Dokumenter bare systeminformasjon læreren har godkjent.
- Ikke publiser interne adresser, identifikatorer eller infrastrukturinformasjon i et offentlig elevrepo.
- Ikke legg inn passord, API-nøkler, private nøkler, personopplysninger eller andre hemmeligheter.
- Registrer små, sammenhengende arbeidssteg med Git.

## Ferdig når

- [ ] `Min systemdokumentasjon` er oppdatert.
- [ ] komponentoversikten beskriver hele IT-laben med utgangspunkt i egen stasjon.
- [ ] fysisk og logisk topologi bruker samme ID-er som komponentoversikten og er eksportert som SVG.
- [ ] systemoversikten forklarer sammenhengene og viser min planlegging, gjennomføring, vurdering og neste steg.
- [ ] minst ett problem er dokumentert med årsak, løsning og kontroll.
- [ ] kildelisten viser hvilke kilder som faktisk er brukt.
- [ ] Git-historikken viser små, beskrivende endringer.
- [ ] en medelev kan følge systemet fra én stasjon gjennom nettverket til en tjeneste og videre til virtuell og fysisk infrastruktur.

## Levering

Fristen publiseres i lærerens tidsplan.

1. Fullfør [sluttkontrollen i steg 3](plan/steg-3-virtualisering-og-systemhelhet.md#sluttkontroll).
2. Eksporter de oppdaterte diagrammene som SVG.
3. Kontroller endringene, registrer siste meningsfulle endring og send den til GitHub.
4. Åpne elevrepoet på GitHub og kontroller at siste endring og SVG-diagrammene vises.

## Hvis du står fast

1. Finn dagens arbeidssteg og ukens kontrollpunkt.
2. Åpne ressursen som står ved arbeidssteget, eller se [eksemplene](ressurser/eksempler.md).
3. Noter hva du prøvde og hva som skjedde.
4. Be om veiledning med ett konkret spørsmål.

Hvis et verktøy eller en labressurs ikke er tilgjengelig, skal du ikke gjette. Dokumenter kort hva som mangler, og fortsett med en annen avtalt del av arbeidet.
